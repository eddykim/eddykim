## 🎓 Background

  Dissertation: *"Snapshot Angle-Resolved Spectroscopic Ellipsometry Using Line-Scan Spectrometer and Back Focal Plane Spectral Interference"*

- 8 years designing and building optical metrology instruments — spectroscopic ellipsometry, Mueller-matrix polarimetry, AI-assisted metrology, spectroscopic reflectometry — spanning hardware, optical design, and analysis software

## 🌱 Focus areas

- **Computational optics** — physics-based forward models + inverse fitting, ML-assisted signal recovery
- **Optical instrument design** — from opto-mechanical alignment and calibration to the analysis software behind it
